1. ¿Qué cambiaría o agregaría?

Mi propuesta es que el dashboard se adapte mejor a las necesidades de cada usuario y al dispositivo desde el que se utiliza. Para lograrlo, agregaría tres mejoras:

Versión para celular: que el tablero se adapte automáticamente a celulares, tabletas y computadoras. En dispositivos pequeños, los indicadores más importantes aparecerían primero y las gráficas se acomodarían de manera vertical para facilitar su lectura.

Modo claro y oscuro: que el dashboard detecte la configuración del dispositivo y cambie automáticamente entre ambos modos. También incluiría una opción para que el usuario pueda elegir el modo que prefiera.

Configuración de preferencias: agregar un apartado donde cada usuario pueda personalizar aspectos básicos, como el tamaño de letra, el modo de visualización y la pantalla de inicio.

2. ¿Para quién sirve y qué decisión le facilita?

Esta mejora serviría para los diferentes usuarios del dashboard. Los analistas, como Adrián y Sofía, podrían consultar sus solicitudes y revisar cuáles necesitan atención primero, incluso desde el celular.

Para la gerencia sería más sencillo revisar los indicadores principales e identificar si hay algún cambio en el riesgo que requiera una decisión. Para soporte, permitiría consultar las alertas del modelo y detectar más fácilmente las fallas que se deben atender.

También ayudaría a que cada persona pueda leer la información con mayor comodidad, sin importar si utiliza el tablero en un lugar con mucha o poca luz.

3. ¿Qué habría que hacer para lograrlo?

Primero, habría que ajustar el diseño para que las tarjetas, gráficas, filtros y botones se acomoden bien en pantallas de diferentes tamaños, sin que se pierda información.

Después, sería necesario preparar los colores y textos para los modos claro y oscuro, agregar la detección automática y dejar un botón para cambiar de modo manualmente.

También se tendría que crear una sección sencilla para guardar las preferencias de visualización de cada usuario, sin permitir que se modifiquen los permisos de acceso.

Por último, habría que probar el dashboard en celular y computadora, con los distintos perfiles, para revisar que la información se vea completa, los botones funcionen y las alertas se entiendan sin depender únicamente de los colores.
